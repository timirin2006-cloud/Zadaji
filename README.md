# Физика 9 класс: движение и свободное падение

Интерактивный конспект и тренажёр для повторения. Открывается в браузере, ничего устанавливать не нужно.

## Что внутри

- **Теория** — короткие карточки с формулами:
  - равномерное прямолинейное движение;
  - равноускоренное прямолинейное движение;
  - свободное падение и ускорение свободного падения `g`.
- **14 задач** трёх уровней: 5 лёгких, 5 средних, 4 сложные.
- У каждой задачи 4 варианта ответа. После выбора сразу видно, верно ли, и появляется **полное решение** по шагам.
- Фильтр по уровню сложности и счётчик верных ответов.
- Светлая и тёмная тема подстраиваются под устройство.

## Темы и формулы

| Тема | Основные формулы |
|---|---|
| Равномерное движение | `s = v·t`, `x = x₀ + v·t` |
| Равноускоренное движение | `a = (v − v₀)/t`, `v = v₀ + a·t`, `s = v₀·t + a·t²/2`, `s = (v² − v₀²)/(2a)` |
| Свободное падение | `v = g·t`, `h = g·t²/2`, `v² = 2·g·h` |
| Бросок вверх | `v = v₀ − g·t`, `H = v₀²/(2g)`, `t_подъёма = v₀/g` |

В задачах принято `g = 10 м/с²` (точнее, `g ≈ 9,8 м/с²`).

## Как запустить

**Локально:** скачай репозиторий и открой файл `index.html` двойным щелчком.

**На GitHub Pages (получится ссылка, которую можно открыть с телефона):**

1. Загрузи `index.html` и `README.md` в репозиторий.
2. Открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту-две сайт появится по адресу `https://<твой-логин>.github.io/<имя-репозитория>/`.

## Структура репозитория

```
.

└── README.md    # это описание
```

## Как добавить свою задачу

В `index.html` найди массив `T` и добавь объект по образцу:

```js
{
  l: "Средняя",                 // уровень: Лёгкая, Средняя или Сложная
  q: "Текст задачи",
  o: ["вариант 1", "вариант 2", "вариант 3", "вариант 4"],
  a: 1,                         // номер верного варианта (считается с 0)
  s: "Решение по шагам"
}
```
